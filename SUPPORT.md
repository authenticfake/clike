# Getting help

- **Start here** — [docs/INSTALL.md](docs/INSTALL.md), [docs/GET_STARTED.md](docs/GET_STARTED.md),
  [CLike at a glance](docs/clike-at-a-glance.md) and the [documentation index](docs/README.md).
- **Questions, ideas, show and tell** — [GitHub Discussions](https://github.com/authenticfake/clike/discussions).
- **Bugs and feature requests** — [GitHub issues](https://github.com/authenticfake/clike/issues/new/choose),
  using the forms.
- **Security problems** — privately, as described in [SECURITY.md](SECURITY.md).

CLike is maintained on a best-effort basis; there is no guaranteed response time.
