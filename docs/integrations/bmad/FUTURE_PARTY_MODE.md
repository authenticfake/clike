# Future Party Mode

Party Mode is a future roadmap item. It is not implemented in the current BMAD integration.

## Possible Direction

Party Mode may eventually coordinate multiple methodology roles around a CLike Harper phase.

Example future use:

```text
analyst + pm + architect review a plan before KIT
developer + qa review a repair strategy after eval
```

## Governance Requirements

Any future Party Mode must:

- keep CLike as workflow owner
- preserve one canonical phase output
- avoid parallel pipelines
- maintain auditability
- keep eval and gate authoritative
- prevent role discussions from expanding write permissions

Party Mode must not let role consensus override CLike gate decisions.
