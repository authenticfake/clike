# BMAD-Aware PLAN Workflow

CLike-owned compact workflow guidance. Make requirements implementation-legible.

- Each REQ must cover functional scope and non-functional requirements.
- Include security, compliance, privacy, observability, and operations obligations when relevant.
- Declare integration contracts, data contracts, dependencies, and dependency assumptions.
- Include acceptance criteria, implementation notes, test strategy, risk, and mitigation.
- Carry TECH_CONSTRAINTS obligations into REQ details.
- State what `/kit` must build now and what later REQs may assume.
- Keep PLAN and `plan.json` canonical under CLike control.
